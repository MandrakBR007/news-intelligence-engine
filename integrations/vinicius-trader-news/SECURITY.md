# Security and data-handling / Segurança e tratamento de dados

EN: No provider SDK, key setup instructions, stored news database, generated dashboard or runtime config from the original package are shipped. Outbound requests require explicit configured feeds and a collect command. The included HTTP endpoints are local, read-only and unauthenticated; do not expose them publicly. Perform independent code review before execution.

PT-BR: Este arquivo não contém SDKs de IA externa, instruções para chaves, banco original de notícias, dashboard gerado nem configuração operacional do remetente. Consultas externas exigem feed configurado e comando de coleta. A interface HTTP local é de leitura e não exige autenticação; não expor na internet. Revisar o código antes de executar.
